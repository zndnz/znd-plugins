# extra_blend_mode.anm2（拡張合成モード）

76 種類の合成モード（各種ライト・覆い焼き・焼き込み、HSV/HSL/HSVL の色相・彩度・輝度、チャンネル入れ替え、平均、ビット演算など）で、このレイヤーを背景に合成する。

- 元のパッケージ: [extra_blend_mode.anm2](https://github.com/sevenc-nanashi/extra_blend_mode.anm2)（作者: sevenc-nanashi、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.extra_blend_mode-anm2`

## znd での使い方

1. 背景（合成先）を 1 つのプリコンポにして置く。
2. 合成するレイヤー（コンポの大きさのシェイプ・テキスト、またはコンポの大きさの平面など）にエフェクト「合成 › 拡張合成モード」を掛け、「背景レイヤー」に 1 を選ぶ。
   結果は「背景と合成した絵」なので、このレイヤーを背景の上にそのまま重ねる（描画モードは通常のまま）。

## 元との違い

- 元はそれまでに描いたフレームバッファと合成する。znd では背景のレイヤーを選ぶ（ほかの znd のエフェクトと同じく、背景の絵はこのレイヤーの画像の大きさに合わせて取り込まれる）。
- 各モードの式は元と同じ（0〜255 の表示値で計算する）。znd 本体の描画モードにあるもの（乗算・スクリーンなど）は、本体の描画モードを使った方が速い。
