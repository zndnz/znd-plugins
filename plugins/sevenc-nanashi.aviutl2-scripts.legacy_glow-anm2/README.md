# 旧発光.anm2

AviUtl1の発光を再現するスクリプト

- 元のパッケージ: [旧発光.anm2](https://github.com/sevenc-nanashi/aviutl2-scripts/tree/main/scripts/%E6%97%A7%E7%99%BA%E5%85%89)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-scripts.legacy_glow-anm2`

## znd での使い方

エフェクト「旧発光」（カテゴリ「光効果」）を掛けると、AviUtl（無印）の「発光」のように、明るさがしきい値を超えた部分から光を広げます。

- 強さ・拡散・しきい値・拡散速度（大きいほど光の芯が強く、遠くまで薄く広がる）
- 光色を使う・光色: 光の色を 1 色にします（使わないと元の色で光る）
- サイズ固定: 光の広がる分だけ周りを広げない

## 元との違い

- 元の PI はありません。光色の有無は「光色を使う」で切り替えます。
- フィルタオブジェクトとして画面全体に掛ける使い方は、znd では調整レイヤーに掛けてください。
