# ベベルとエンボス.anm2

輪郭に光と影を付けベベル・エンボスを作るスクリプト

- 元のパッケージ: [ベベルとエンボス.anm2](https://github.com/sevenc-nanashi/aviutl2-scripts/blob/main/scripts/%E3%83%99%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A8%E3%83%B3%E3%83%9C%E3%82%B9/README.md)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-scripts.bevel_and_emboss-anm2`

## znd での使い方

エフェクト「ベベルとエンボス」（カテゴリ「加工」）を掛けると、絵の輪郭に光（ハイライト）と影（シャドウ）を付けて、浮き彫りや面取りのように見せます。

- 形状: ベベル（外側）/ ベベル（内側）/ エンボス / ピローエンボス
- 幅・角度（光の向き）・高度（光の高さ。上げるほど弱くなる）
- α閾値: 輪郭とみなすアルファ、参照輪郭ぼかし: 輪郭を探す前のぼかし、ぼかし: 光と影に掛けるぼかし
- 出力: 通常合成（背景色の上に組み立てる）/ 直接描画（元の絵の上に重ねる）/ ハイライトのみ / シャドウのみ
- ハイライト・シャドウそれぞれの色・合成モード・不透明度

## 元との違い

- 「直接描画」は、元はフレームバッファに直接描きますが、znd では元の絵の上に重ねた結果を出します。
- 元の PI はありません。
