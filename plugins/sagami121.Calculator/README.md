# Aviutl2-Calculator

AviUtl2上で計算ができるプラグイン

- 元のパッケージ: [Aviutl2-Calculator](https://github.com/sagami121/Aviutl2-Calculator)（作者: 3aGaM1、ライセンス: MIT）
- カタログ ID: `sagami121.Calculator`

## znd での使い方

「プラグイン」メニューから「電卓」パネルを開くと、四則演算ができます（% は 100 で割る、± は符号を反転、CE は入力中の数を消す、C はすべて消す、← は 1 文字消す）。「結果をコピー」で表示中の数をクリップボードに入れます。

## 元との違い

- 「結果をコピー」は znd で足したボタンです。
- 数は小数第 12 位で丸めて表示します（浮動小数の誤差を見せないため）。
