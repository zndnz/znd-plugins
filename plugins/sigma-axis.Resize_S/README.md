# Resize_S

拡大縮小のアルゴリズムを選べるリサイズフィルタ

- 元のパッケージ: [Resize_S](https://github.com/sigma-axis/aviutl2_script_Resize_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.Resize_S`

## znd での使い方

エフェクトが 2 つ入っています（カテゴリ「変形」）。

### リサイズσ

レイヤーの絵を、選んだアルゴリズムで拡大縮小します。

- 拡大率・X・Y: 全体の倍率と、縦横それぞれの倍率（%）。「ピクセル数でサイズ指定」を入れると X・Y が出来上がりの幅・高さ（px）になります
- 拡大方法: 最近傍法 / 双線形 / Mitchell-Netravali / Catmull-Rom / Lanczos2 / Lanczos3
- 縮小方法: 最近傍法 / 単純平均 / 双線形 / Hamming / Lanczos2 / Lanczos3

### ボックスリサイズσ

X × Y の矩形に合うように拡大縮小します。

- モード: 内接最大（矩形に収まる最大の大きさ）/ 外接最小（矩形を覆う最小の大きさ）
- 拡大縮小: 拡縮両方 / 拡大のみ / 縮小のみ
- 余白/クリッピング: 縦横比が違うとき、内接最大なら余白を足し、外接最小ならはみ出た分を切って、ちょうど矩形の大きさにします。水平揃え・垂直揃え（-100～100）で余白や切る量の左右・上下の配分を決めます

## 元との違い

- 元の「中心の位置を変更」はありません。znd では絵の中心を保ったまま大きさが変わります。
- ボックスリサイズσの「背景サイズ」（シーンの大きさに合わせる）はありません。X・Y にコンポジションの大きさを入れてください。
- 元の PI（スクリプトからの指定）はありません。
- 外接最小で切るときは、全体を拡大縮小してから切ります（元は先に切ってから拡大縮小します。結果はほぼ同じです）。
- 拡大のときも重みの合計で割ります。負のローブではみ出た色は 0～アルファの範囲に収めます。
