# Glitch_T

スライスの横ずれ・RGB のずれ・縦ずれ・色の帯・砂嵐・走査線を重ねるデジタルグリッチ。

- 元のパッケージ: [Glitch_T](https://github.com/sagami121/Glitch_T)（作者: sagami121、ライセンス: MIT）
- カタログ ID: `sagami121.Glitch_T`

## znd での使い方

エフェクト「スタイライズ › Glitch_T」。速度でフレームごとの変化の速さ、合成モードでノイズの重ね方を選ぶ。

## 元との違い

計算は元のシェーダーと同じ（プリマルチプライドの表示値で計算し、リニアに戻す）。長さ（スライス高さ・ずれ・砂嵐の粒子・走査線）はレイヤー座標の px なので、プレビュー解像度を下げても見た目が変わらない。
