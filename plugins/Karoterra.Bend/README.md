# 曲げKR

画像を曲線に沿って曲げるスクリプト

- 元のパッケージ: [曲げKR](https://github.com/karoterra/aviutl2-Bend)（作者: かろてら、ライセンス: MIT）
- カタログ ID: `Karoterra.Bend`

## znd での使い方

エフェクトが 2 つ入っています（カテゴリ「変形」）。どちらも、始点と終点（オブジェクトの中心からの px）を結ぶ線を軸にして、その間を曲線に沿って曲げます。始点より手前・終点より先は、曲線の端の向きに合わせて回るだけで曲がりません。

### 円弧@曲げKR

- 曲率: 0 から離れるほど強く曲がります（正負で曲がる向きが変わる）
- 割合: 始点と終点の間のどこを曲がりの中心にするか（%）
- 破綻回避: 曲率が大きくて円の中心を越えた部分が裏返らないようにします

### ベジェ曲線@曲げKR

始点・制御点1・制御点2・曲線の終点の 3 次ベジェ曲線に沿わせます。始点から終点までの長さを、曲線に沿った長さに合わせて写します。

### 共通

- 分割数・細分化: 曲げの細かさ（大きいほどなめらか）
- 始点・終点: 入れないと、始点より手前・終点より先を描きません
- 中心: 曲げたあとの絵のどこを元の中心に合わせるか

## 元との違い

- 元の「アンカー表示」（プレビューに印と元の絵を出す）はありません。始点などは数値で指定します。
- 元は始点と終点の間を帯に分けて drawpoly で描きますが、znd では絵全体を細かい格子にして写します（格子の細かさは分割数×細分化から決めます）。
- ベジェ曲線の「破綻回避」と「積分ステップ」はありません（積分の刻みは 0.001 で固定）。
- 円弧の破綻回避は、元の四角形の付け替えではなく、半径を 0 で止めるやり方です。
