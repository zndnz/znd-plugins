# audio2obj

音声ファイル名からオブジェクト生成

- 元のパッケージ: [audio2obj](https://github.com/rokujyushi/GCMZScripts)（作者: 黒猫大福、ライセンス: MIT）
- カタログ ID: `KuroNeko.audio2obj`

## znd での使い方

音声のレイヤーを選んで、コマンド「音声のファイル名からセリフを作る」（「プラグイン」メニューとレイヤーの右クリック）を実行すると、そのファイル名（拡張子なし）を文字にしたテキストレイヤーを、同じ長さで音声のすぐ上に作ります。「（キャラクターID_セリフ）」の方は、ファイル名を「_」で区切った 2 つ目以降をセリフにします。

## 元との違い

- 元は GCMZDrops2 で音声ファイルをドロップしたときに、PSDToolKit の「セリフ準備」オブジェクトを作るハンドラーです。znd にはドロップの拡張も PSDToolKit もないので、読み込んだ音声レイヤーからテキストレイヤーを作るコマンドにしました。
