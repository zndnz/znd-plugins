# 油絵

桑原フィルタで、油絵のような平坦な色の塊にする。

- 元のパッケージ: [aviutl2-OilPainting](https://github.com/karoterra/aviutl2-OilPainting)（作者: Karoterra、ライセンス: MIT）
- カタログ ID: `Karoterra.OilPainting`

## znd での使い方

エフェクト「スタイライズ › 油絵」。ぼかし（領域の大きさ px）と輝度モード（加重平均・平均・最大値）。

## 元との違い

計算は同じ（4 つの正方形の分散が最小の領域の平均色。分散が同じなら後の領域を選ぶ）。積分画像で高速化している。
ぼかしの大きさはレイヤー座標の px なので、プレビュー解像度を下げても見た目が変わらない。
