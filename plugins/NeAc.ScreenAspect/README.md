# 画面アスペクト

画面の中央に、指定した縦横比の長方形を描く。「反転」で長方形の外側を塗る（4:3 の枠に黒帯を付けるなど）。

- 元のパッケージ: [aviutl2_script_ScreenAspect](https://github.com/nea-c/aviutl2_script_ScreenAspect)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.ScreenAspect`

## znd での使い方

コンポと同じ大きさの平面に、エフェクト「描画 › 画面アスペクト」を掛ける。適応度 100% で画面に内接する大きさ、0% で画面いっぱい（キーフレームで切り替えの演出ができる）。

## 元との違い

- 「ピクセル数表示」（長方形の大きさを文字で出す）は無い。必要ならテキストレイヤーで表示する。
- 「スクリーン」はエフェクトを掛けたレイヤーの画像の大きさ。
