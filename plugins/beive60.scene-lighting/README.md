# シーンライティング

背景の環境光の色を前景のオブジェクトに馴染ませる。背景の代表色を前景に合成し、輪郭から光が回り込むライトラップと、指定方向のリムライトを足す。

- 元のパッケージ: [aviutl2-scene-lighting](https://github.com/beive60/aviutl2-scene-lighting)（作者: beive60、ライセンス: MIT）
- カタログ ID: `beive60.scene-lighting`

## znd での使い方

前景のレイヤーにエフェクト「光 › シーンライティング」を掛け、「背景レイヤー」に背景のレイヤーを選ぶ（選ばなければ灰色を環境光にする）。

## 元との違い

- 背景はレイヤー番号の差（-1 = 1 つ下）ではなく、レイヤーを直接選ぶ。
- 計算は元と同じ（エッジ検出・ライトラップ・リムライトはシェーダーの式のまま。長さはレイヤー座標の px）。
