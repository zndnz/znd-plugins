# 波形ライン

マウスで描いた線を音声波形で揺らすカスタムオブジェクト

- 元のパッケージ: [波形ライン](https://github.com/ar-ca-na/aviutl2-waveform-line)（作者: arcana、ライセンス: MIT）
- カタログ ID: `ar-ca-na.waveform-line`

## znd での使い方

1. 図形や平面などのレイヤーにマスクのパスを描き（ペンツール）、マスクのモードを「なし」にします。
2. そのレイヤーにエフェクト「波形ライン」を掛けると、マスクのパスが線として描かれます（元の絵は消えます。「元の絵を残す」で重ねて描けます）。
3. 「モード」を「波形にする」にして「音声レイヤー」を選ぶと、線がその音声の波形で揺れます。

- 太さ・色・色2（「グラデーション」を入れると線の始まりから終わりへ色が変わる）
- 描く割合: 線の始まりから何 % まで描くか（キーフレームで描き順のアニメーション）
- 破線の長さ・すき間: 両方 0 より大きいと破線になります
- 波形の振幅・波の回数・波形の形（なめらか / 四角）・波形をならす
- 手描きのブレ: 波形モードで音が鳴っている間、3 フレームごとに線がゆるくうねります
- 閉じたパスは輪として描かれ、つなぎ目の揺れが滑らかにつながります

## 元との違い

- 元はプレビュー上でマウスでドラッグして線を描き、「操作」（1 つ戻す・全部消す・輪にする）で編集しますが、znd ではレイヤーのマスクのパスを線として使います。編集は znd のマスク編集で行い、輪にするかはパスを閉じるかで決まります。
- 「描かない」モードはエフェクトを無効にすることで代わりになります。
- 元は描いた点を Catmull-Rom でなめらかにつなぎますが、znd のマスクはベジェ曲線なので、そのまま折れ線にして使います。
- 手描きのブレの乱数は znd のシードを使うので、元と同じ形にはなりません。
