# Kaleidoscope_K（万華鏡）

画像を万華鏡のように折り返して敷き詰める。折り返し方は 10 種類（Unfold・Wheel・Fish Head・Can Meas・Flip Flop・Flower・Dia Cross・Flipper・Starlish・Tiler）。

- 元のパッケージ: [AviUtl2_Kaleidoscope_K_Script](https://github.com/korarei/AviUtl2_Kaleidoscope_K_Script)（作者: korarei、ライセンス: MIT）
- カタログ ID: `korarei.Kaleidoscope_K`

## znd での使い方

エフェクト「ディストーション › 万華鏡（Kaleidoscope_K）」。中心はビューアでドラッグできる。

## 元との違い

計算は元のシェーダーと同じ（画面外はミラーで折り返して取る）。`PI`（パラメータ注入）は無い。
