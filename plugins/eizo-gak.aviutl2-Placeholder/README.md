# プレースホルダー

背景・対角線・枠線の付いた仮置きの四角形を出す（後で素材に差し替える場所の目印）。

- 元のパッケージ: [aviutl2-Placeholder](https://github.com/eizo-gak/aviutl2-Placeholder)（作者: eizo-gak、ライセンス: MIT）
- カタログ ID: `eizo-gak.aviutl2-Placeholder`

## znd での使い方

平面レイヤー（大きさは何でもよい）にエフェクト「描画 › プレースホルダー」を掛ける。平面の絵は、指定した幅・高さのプレースホルダーに置き換わる（平面の中心に置く）。

## 元との違い

- AviUtl2 の「カスタムオブジェクト」の代わりに、平面に掛けるエフェクトにした。ABI 3 の出力の大きさの変更で、平面の大きさと関係なく指定の大きさで描く。
- 「プレビュー画面のリサイズを禁止」（AviUtl2 のプレビューの操作）は無い。
