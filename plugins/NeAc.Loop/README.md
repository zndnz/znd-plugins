# Loop

オブジェクトを縦横に並べて複製する。間隔はオブジェクトの大きさに対する %（「個別基準」で px）。行ごと・列ごとにずらす（オフセット）こともできる。

- 元のパッケージ: [aviutl2_script_Loop](https://github.com/nea-c/aviutl2_script_Loop)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.Loop`

## znd での使い方

エフェクト「配置 › Loop（並べて複製）」。並べた全体が収まるよう、レイヤーの画像が広がる（ABI 3 の出力の大きさの変更）。
個数を負にすると逆向きに並ぶ。

## 元との違い

- Z 方向（奥行き）の個数・間隔・オフセットは無い（znd のエフェクトは 2D の画像を作る）。
- 「個別オブジェクト」（複製を別々のオブジェクトとして後続のフィルタに渡す）は無い。複製のあとに掛けたエフェクトは、並べた全体に掛かる。
