# ドカベン.anm2

ドカベン風に文字を登場させるスクリプト

- 元のパッケージ: [ドカベン.anm2](https://github.com/sevenc-nanashi/aviutl2-scripts/tree/main/scripts/%E3%83%89%E3%82%AB%E3%83%99%E3%83%B3)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-scripts.dokaben-anm2`

## znd での使い方

エフェクト「ドカベン」（カテゴリ「アニメーション」）を掛けると、レイヤーの始まりで絵が手前に倒れた状態から起き上がります（ドカベンの文字の動き）。

- 再生速度（%）: 0 で起き上がった状態のまま
- 自動で倒れる・直立時間: 起き上がってから直立時間（フレーム）待って倒れ、を繰り返します
- Yオフセット: 変形の基準の高さ
- コマ落ち: 動きをカクカクにします

## 元との違い

- AviUtl2 ではテキストを 1 文字ずつのオブジェクトにして文字ごとに動かせますが、znd のエフェクトはレイヤーの絵全体に掛かります。1 文字ずつ動かすときは、文字ごとのレイヤーに分けて掛けてください。
- 元の PI（分割数の指定など）はありません。
