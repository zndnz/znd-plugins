# BPMグリッド倍化

グリッドの設定のBPM値を倍々に変化&BPM測定

- 元のパッケージ: [BPMグリッド倍化](https://github.com/Garech-mas/DoubleBPMGrid)（作者: Garech、ライセンス: MIT）
- カタログ ID: `Garech.DoubleBPMGrid`

## znd での使い方

「プラグイン」メニューから「BPMグリッド倍化」パネルを開くと、コンポのビートグリッドの BPM・拍子・オフセットが出ます。

- ×N・÷N: BPM を N 倍・N 分の 1 にします（N は「変更倍率」の 2〜8。拍子はそのまま）
- ＜・＞: グリッドの基準（オフセット）を 1 フレームずつ動かします
- ＋ ここを基準: 再生ヘッドの位置をグリッドの基準にします
- BPMを測定する: 拍に合わせて何度も押すと、押した間隔から BPM（整数・4 拍子）を決めてグリッドに入れます。2 秒以上あけると測り直します

## 元との違い

- AviUtl2 の BPM グリッドは区間ごとに BPM を持てますが、znd のビートグリッドは 1 つなので、すべて 1 つのグリッドに対して働きます。
- 「BPMを元に戻す」はありません。znd の取り消し（⌘Z）で戻せます。
