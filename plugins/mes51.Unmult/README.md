# Unmult

黒（または白）の背景を透明にする。明るい部分ほど不透明になるよう、色の最大値をアルファに置き換える（光の素材を「スクリーン」なしで重ねるため）。

- 元のパッケージ: [AVIUtl2_Unmult](https://github.com/mes51/AVIUtl2_Unmult)（作者: mes51、ライセンス: MIT）
- カタログ ID: `mes51.Unmult`

## znd での使い方

エフェクト「キーイング › Unmult（背景を透明に）」。背景色で黒・白を選ぶ。

## 元との違い

元と同じく表示値（sRGB）で計算する。znd の画像はリニアライトなので、いったん表示値に直して計算し、戻している。
