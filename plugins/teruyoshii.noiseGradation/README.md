# ノイズグラデーション

時間制御カーブで自由に調整できるノイズグラデーション

- 元のパッケージ: [ノイズグラデーション](https://x.com/teruyoshi_uec/status/1979927691215471002)（作者: てるよし、ライセンス: MIT）
- カタログ ID: `teruyoshii.noiseGradation`

## znd での使い方

エフェクト「ノイズグラデーション」（カテゴリ「色調整」）を掛けると、開始色と終了色をノイズやディザの模様で塗り分け、終了色の割合が少しずつ増えるグラデーションにして重ねます。

- ノイズの種類: ホワイトノイズ・ブルーノイズ・IGN・配列ディザリング（2×2 / 4×4 / 8×8）・集中型ディザリング・網点・線（網点と線は「模様の周期」「模様の角度」で決まる）
- ドットサイズX・Y: 模様の 1 粒の大きさ
- 形状（線形・円形）、中心X・Y、角度/内径、幅、開始色・終了色と透明度、合成モード、強さ、シード
- グラデ曲線: 「グラデ曲線を使う」を入れると、「グラデ曲線0→100」に打ったキーフレームの変化（レイヤーの始まりから終わりまで）を、終了色の割合の進み方として使います
- 元オブジェクトをクリア: 元の絵を消してグラデーションだけにします

## 元との違い

- 元の「時間制御」で描くグラデ曲線は、znd ではパラメータのキーフレームで描きます。
- 合成モードのアルファ加算・アルファ最大値・アルファ減算・アルファ加算2 はありません。
- 元はドットサイズで縮めた絵に模様を作ってから拡大し直しますが、znd では縮めた座標で直接計算します（見た目は同じです）。
