# 中心ずらし_A

オブジェクトの中心座標を移動するスクリプト

- 元のパッケージ: [中心ずらし_A](https://github.com/azurite581/AviUtl2-AdjustPivot_A)（作者: azurite、ライセンス: MIT）
- カタログ ID: `azurite.AdjustPivot_A`

## znd での使い方

「プラグイン」メニューから「中心ずらし」パネルを開き、レイヤーを選んで 9 つのボタン（左上・上・右上・左・中心・右・左下・下・右下）のどれかを押すと、そのレイヤーのアンカーポイント（回転・拡大の中心）が絵のその位置に移ります。

- オフセットX・Y: 選んだ位置からのずれ（px）
- オブジェクトを移動: 入れないと絵はその場に残り、中心だけが動きます（位置にもエクスプレッションを付けます）。入れると中心の位置は変えずに絵が動きます
- 外す: 付けたエクスプレッションを外します

エクスプレッションの関数 `adjustPivotAnchor(位置, X, Y)`・`adjustPivotPosition(value, 位置, X, Y)` は手で書いても使えます。絵の大きさが変わっても毎フレーム付いていきます。

## 元との違い

- 元はエフェクトとして掛けますが、znd ではエフェクトから中心を動かせないので、アンカーポイントと位置のエクスプレッションで同じことをします。
- 「絵をその場に残す」計算は、アンカーポイントが絵の中心にある（znd の既定）ことを前提にしています。
- 元の PI はありません。
