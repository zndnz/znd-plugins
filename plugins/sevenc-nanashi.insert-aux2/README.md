# insert.aux2

「メディアを挿入」編集メニューを追加する汎用プラグイン

- 元のパッケージ: [insert.aux2](https://github.com/sevenc-nanashi/insert.aux2)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.insert-aux2`

## znd での使い方

コマンド「メディアを挿入」（「プラグイン」メニューとツールバー）を実行して素材を選ぶと、再生ヘッドの位置に読み込みます。ショートカットは znd の設定で割り当てられます（Reaper の Insert キーのような使い方）。

## 元との違い

- 読み込み先は znd の読み込みと同じく、再生ヘッドの位置の新しいレイヤーです。
