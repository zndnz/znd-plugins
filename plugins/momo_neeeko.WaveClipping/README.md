# ウェーブクリッピング

様々な波の形で斜めクリッピング

- 元のパッケージ: [ウェーブクリッピング](https://x.com/momo_neeeko/status/2037491184260784191)（作者: もも猫、ライセンス: MIT）
- カタログ ID: `momo_neeeko.WaveClipping`

## znd での使い方

エフェクト「ウェーブクリッピング」（カテゴリ「クリッピング」）を掛けると、中心X・Y を通り角度の向きに伸びる波の線で絵を切り取ります。

- 波長（0 なら振幅×4）・振幅・位相・波形（正弦波 / 三角波 / 矩形波 / ノコギリ波 / 正弦波の絶対値 / ランダム）
- クリッピング方法: 一方向（線の片側を消す）/ 双方向（幅の帯だけ残す）/ 双方向(反転)（幅の帯だけ消す）

## 元との違い

- 中心はプレビュー上のアンカーではなく数値で指定します。
