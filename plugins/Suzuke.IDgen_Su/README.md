# IDgen_Su

UUID（v4・v7）・NanoID・ULID・CUID・ShortID・KSUID・Snowflake の形式の「それらしい ID」を表示する（画面の中の UI・ログの演出用）。

- 元のパッケージ: [IDgen_Su](https://github.com/Suzukeh/IDgen_Su)（作者: Suzuke、ライセンス: MIT）
- カタログ ID: `Suzuke.IDgen_Su`

## znd での使い方

テキストレイヤーを置き、「プラグイン › IDgen_Su」パネルで種別とシードを決めて「ID にする」。本文が `idgen(…)` のエクスプレッションになる。
「毎フレーム更新」でフレームごとに違う ID、「レイヤーごとに変える」で選んだレイヤーごとに違う ID になる。

## 元との違い

- 元はカスタムオブジェクトで文字を描く。znd ではテキストレイヤーの本文をエクスプレッションで作るので、フォント・大きさ・色・揃えはテキストレイヤーで決める。
- 乱数は AviUtl の `obj.rand1` と同じではない（同じシードでも同じ ID にはならない）。CUID の連番は 1 に固定。時刻を含む形式は、「毎フレーム更新」のときだけ時刻が進む。
