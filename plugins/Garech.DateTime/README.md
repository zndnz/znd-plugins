# 日付と時刻

時間変化する日付と時刻を表示します。カウンターとしても使えます。

- 元のパッケージ: [日付と時刻](https://www.nicovideo.jp/watch/sm36307237)（作者: Garech、ライセンス: CC0-1.0）
- カタログ ID: `Garech.DateTime`

## znd での使い方

「プラグイン」メニューから「日付と時刻」パネルを開き、設定を決めてテキストレイヤーを選び「付ける」を押すと、そのテキストが時間とともに変わる日付と時刻になります（テキストのエクスプレッションを付けます）。

- 開始日時と表示形式（8 種のプリセットかカスタム）。記号は元と同じです（yyyy・mm・mmm・dd・ddd・aaa・ggg・ee・kk・hh・nn・ss・午前/午後・a.m./p.m. など。$ は次の 1 文字をそのまま出す）
- 数字の半角/全角・フィールド文字・大文字・序数・元年表記
- 加算時間・速度（再生 1 秒あたり）・推移（開始日時から終了日時へ）
- 経過時間モード: 基点からの経過時間を出します（フィールド幅・最上位の単位）

エクスプレッションの関数 `dateTimeText({...})` は手で書いても使えます。

## 元との違い

- 元はカスタムオブジェクトとして文字を描きますが、znd ではテキストレイヤーの文字をエクスプレッションで作ります（フォント・色・縁取りはテキストレイヤーで決めます）。
- 経過時間モードの基点「最初/最後のフレーム」は、推移を一定の値として計算します（推移にキーフレームを打った場合の、最初・最後の値は使いません）。
- 「加算時間100分割」はありません（加算時間は小数でも指定できます）。
