# ルーローの多角形

ルーローの多角形のカスタムオブジェクト

- 元のパッケージ: [ルーローの多角形](https://drive.google.com/file/d/1X7q80FYOqJINB2CIKaJ5A9nHXAusRX0r/view?usp=drive_link)（作者: もも猫、ライセンス: MIT）
- カタログ ID: `momo_neeeko.ReuleauxPolygon`

## znd での使い方

平面レイヤーにエフェクト「描画 › ルーローの多角形」を掛けると、平面の中心にルーローの多角形を描きます（元の絵は置き換わります）。頂点数は 2n+1（n を指定）です。

## 元との違い

- 縁は元の「ぼかし 1px」の代わりに超標本化でなめらかにします。
