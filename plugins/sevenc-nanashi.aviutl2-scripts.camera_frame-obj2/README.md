# カメラフレーム.obj2

カメラフレームっぽい図形を描画するスクリプト

- 元のパッケージ: [カメラフレーム.obj2](https://github.com/sevenc-nanashi/aviutl2-scripts/blob/main/scripts/%E3%82%AB%E3%83%A1%E3%83%A9%E3%83%95%E3%83%AC%E3%83%BC%E3%83%A0/README.md)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-scripts.camera_frame-obj2`

## znd での使い方

平面レイヤーにエフェクト「描画 › カメラフレーム」を掛けると、平面の中心に、四隅に L 字の線を引いた枠を描きます（元の絵は置き換わります）。

- サイズ指定: 余白指定（幅・高さは画面の端からの余白）/ 絶対指定（幅・高さがそのまま枠の大きさ）
- 線の長さ・線の太さ・線の色

## 元との違い

- 元の PI とデバッグモードはありません。
- 「余白指定」の画面の大きさはコンポの大きさです。
