# JpegNoise_for_AviUtl2

JPEG圧縮特有のブロックノイズや色のにじみを再現するスクリプト。

- 元のパッケージ: [JpegNoise_for_AviUtl2](https://github.com/SagyouDarui900/JPEGNoise_AviUtl2)（作者: サ行、ライセンス: MIT）
- カタログ ID: `Sagyou.JpegNoise`

## znd での使い方

エフェクト「JPEGノイズ」（カテゴリ「加工」）を掛けると、JPEG と同じ 8×8 の DCT 圧縮をして、ブロックノイズや色のにじみを出します。

- 品質: 低いほど粗くなります
- インターレース: 残す周波数の数（1～64。小さいほどぼやけたブロックになる）
- 透明度も圧縮: アルファも圧縮します
- サイズ倍率・Xズレ・Yズレ: ブロックの大きさ（8 px の何倍か）と、ブロックの格子のずれ

## 元との違い

- 元と同じく表示値（sRGB）の 0～255 で計算します。
- 元のオブジェクトの不透明度を掛ける処理はありません（znd ではレイヤーの不透明度が別に掛かります）。
