# 墨だまり

文字の角や細い隙間に墨が溜まったように、輪郭の凹んだところを丸く埋めて 1 色で塗る（膨張してから収縮するクロージング）。

- 元のパッケージ: [AviUtl2_SumiDamari](https://github.com/5qlufz-1536/AviUtl2_SumiDamari)（作者: saluf、ライセンス: MIT）
- カタログ ID: `saluf.SumiDamari`

## znd での使い方

テキストなどのレイヤーにエフェクト「スタイライズ › 墨だまり」を掛ける。溜まり半径は px（最大 20）、丸め強度 0 で角ばった溜まり、100 で丸い溜まり。

## 元との違い

- 塗る色は、元はテキストの文字色を読む。znd ではレイヤーのいちばん不透明な画素の色を使う（元の、文字色が読めなかったときの方法と同じ）。「色を指定する」で決めた色にもできる。
