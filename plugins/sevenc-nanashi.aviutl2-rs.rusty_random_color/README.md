# Rusty Random Color Filter

ランダムな色の正方形のカスタムオブジェクトを作成するプラグイン

- 元のパッケージ: [Rusty Random Color Filter](https://github.com/sevenc-nanashi/aviutl2-rs)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-rs.rusty_random_color`

## znd での使い方

平面レイヤーにエフェクト「描画 › Rusty Random Color」を掛けると、平面の中心にランダムな色の四角形・楕円・三角形（Shape）を Width × Height の大きさで描きます。

## 元との違い

- 元は最初に描いたときに色を決めてプロジェクトに覚えますが、znd ではレイヤーのシードと「色の番号」から色を決めます。色を変えたいときは「色の番号」を変えてください。
