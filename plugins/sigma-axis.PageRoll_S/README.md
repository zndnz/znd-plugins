# PageRoll_S

ページを丸めるように画像を変形するスクリプト

- 元のパッケージ: [PageRoll_S](https://github.com/sigma-axis/aviutl2_script_PageRoll_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.PageRoll_S`

## znd での使い方

エフェクト「PageRoll_S」（カテゴリ「変形」）を掛けると、紙を端から丸めて巻き取るように絵を変形します。

- 距離: 端から巻き取った長さ、角度: 巻き取る向き（0 で真上へ、時計回りに正）、太さ: 巻いた部分の太さ
- 視点X・Y・視野角: 見る位置と遠近の強さ、陰影: 巻いた部分の影の強さ
- 領域外も描画: 巻いた部分が絵の外にはみ出したら広げる
- 裏地レイヤー: 巻いた部分の裏に見せる絵（選ばないと元の絵）。元の絵の縦横比に合わせて中央を切り抜きます。裏地向きで向きを変えられます

## 元との違い

- 裏地は画像ファイル・フレームバッファ・仮想バッファ・キャッシュの代わりに、レイヤーで選びます（画像ファイルを使うときは、画像のレイヤーを置いて非表示にしてください）。
- 元の PI はありません。
