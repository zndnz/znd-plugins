# RainOnPane（窓の雨）

窓ガラスに付いた雨粒と、流れ落ちる雨筋。雨粒・雨筋の屈折、流れた跡が曇り・雨粒を拭って時間とともに戻る、すりガラス・曇り、四隅の変形（斜めの窓）。

- 元のパッケージ: [aviutl2_script_RainOnPane](https://github.com/nctype/aviutl2_script_RainOnPane)（作者: nctype、ライセンス: MIT）
- カタログ ID: `nctype.RainOnPane`

## znd での使い方

窓の外の絵の上に**調整レイヤー**を置き、エフェクト「スタイライズ › 窓の雨（RainOnPane）」を掛ける。「四隅変形」で、ガラスの範囲を 4 つの点（ビューアでドラッグ）で決められる。

## 元との違い

- 元はカスタムオブジェクトでフレームバッファを読む。znd では調整レイヤーのエフェクトとして下の絵を受け取る。
- 計算は元のシェーダーと同じ（長さはレイヤー座標の px）。曇りのぼかしは元の 13 タップの二項分布の代わりにガウスぼかし。「軽量プレビュー」は無い。
