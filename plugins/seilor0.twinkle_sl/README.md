# twinkle_sl

✨ の形を描く。直線で作る「直線」と、スーパー楕円のような曲線で作る「カーブ」の 2 種類。塗りと線（内側・中央・外側）。

- 元のパッケージ: [twinkle_sl](https://github.com/seilor0/twinkle_sl)（作者: seilor0、ライセンス: MIT）
- カタログ ID: `seilor0.twinkle_sl`

## znd での使い方

平面レイヤー（大きさは何でもよい）に、エフェクト「描画 › twinkle_sl（直線）」または「twinkle_sl（カーブ）」を掛ける。平面の中心に図形が描かれる。

## 元との違い

- 「カスタムオブジェクト」の代わりに、平面に掛けるエフェクト（出力の大きさは図形の大きさになる）。距離関数は元のシェーダーと同じ。
