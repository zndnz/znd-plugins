# Mosaic_C

シャープなモザイク

- 元のパッケージ: [Mosaic_C](https://github.com/CatWithNeko/aviutl2-scripts#mosaic_c)（作者: こんにゃくねこ、ライセンス: CC0-1.0）
- カタログ ID: `CatWithNeko.Mosaic`

## znd での使い方

エフェクト「Mosaic_C」（カテゴリ「加工」）を掛けると、絵の中心から Size px の升目に区切り、各升目の中心の色で塗ります。sizeX・sizeY（0～1）で升目の縦横の比率を変えられます。

## 元との違い

- 升目の色は元と同じく升目の中心を 1 点だけ拾います（平均しないのでくっきりします）。
