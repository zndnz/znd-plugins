# TextSplitter

テキストオブジェクトを1文字ずつのオブジェクトに一括分割するプラグイン

- 元のパッケージ: [TextSplitter](https://github.com/Natadecoco2539/AviUtl2-TextSplitter)（作者: なたのこ、ライセンス: MIT）
- カタログ ID: `Natadecoco.TextSplitter`

## znd での使い方

テキストレイヤーを選んでコマンド「テキスト分割」（「プラグイン」メニューとレイヤーの右クリック）を実行すると、1 文字ずつのテキストレイヤーに分けます（空白は除きます）。分けた文字は元と同じ位置に並ぶので、そのあと 1 文字ずつ動かせます。

## 元との違い

- 分けたレイヤーは、元と同じ文章に「その文字以外を透明にする」アニメーターを付けたものです。文字の位置・フォント・行送りが元とまったく同じになります。
- 回転や拡大の中心（アンカーポイント）は元の文章のままです。文字の中心で回したいときは、中心ずらし_A の移植などで動かしてください。
