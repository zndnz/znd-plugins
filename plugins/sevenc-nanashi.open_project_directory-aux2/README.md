# open_project_directory.aux2

「プロジェクトファイルのフォルダを開く」ボタンを追加する汎用プラグイン

- 元のパッケージ: [open_project_directory.aux2](https://github.com/sevenc-nanashi/open_project_directory.aux2)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.open_project_directory-aux2`

## znd での使い方

「プラグイン」メニューに 3 つのコマンドが入ります。

- プロジェクトファイルのフォルダを開く（Finder・エクスプローラーなどで開く）
- プロジェクトファイルのフォルダのパスをコピー
- プロジェクトファイルのパスをコピー

プロジェクトをまだ保存していないときは知らせます。

## 元との違い

- AviUtl2 の「編集」メニューではなく、znd の「プラグイン」メニューに入ります（ショートカットは割り当てられます）。
