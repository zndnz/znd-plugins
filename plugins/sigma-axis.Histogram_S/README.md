# Histogram_S（ヒストグラム）

画像の色の分布（ヒストグラム）を表示する編集補助。XYZ・RGB・sRGB（リニア）・Oklab・OKLCH・YUV（BT.601/709/2020）・HSV・HSL の 12 種類の色空間。

- 元のパッケージ: [aviutl2_script_Histogram_S](https://github.com/sigma-axis/aviutl2_script_Histogram_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.Histogram_S`

## znd での使い方

平面レイヤーにエフェクト「編集補助 › ヒストグラム（Histogram_S）」を掛け、「対象のレイヤー」に調べたいレイヤーを選ぶ（選ばなければそのレイヤー自身）。
画面全体を調べたいときは、調べたい部分をプリコンポにして選ぶ。書き出しに入れたくないときは、このレイヤーをガイドレイヤー・非表示にする。

## 元との違い

- 「対象」のフレームバッファ・レイヤー番号の指定の代わりに、レイヤーを選ぶ。
- 軸のラベル（R・G・B などの文字）と「表示モード（動画出力中は非表示）」は無い（プラグインは文字を描けず、書き出し中かどうかも分からないため）。
- 統計と描画の計算は元のシェーダーと同じ。
