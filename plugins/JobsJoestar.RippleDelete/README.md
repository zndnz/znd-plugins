# リップル削除

リップル削除を追加する汎用プラグイン

- 元のパッケージ: [リップル削除](https://github.com/Joster777/Aviutl2_Plugin_RippleDelete)（作者: JobsJoestar、ライセンス: MIT）
- カタログ ID: `JobsJoestar.RippleDelete`

## znd での使い方

レイヤーを選び、再生ヘッドを残したい部分の始まりに置いて、コマンド「リップル削除」（「プラグイン」メニューとレイヤーの右クリック）を実行すると、そのレイヤーの先頭から再生ヘッドの手前までを取り除き、残りを元の開始位置へ詰めます。中身（動画の再生位置など）はずれません。元の終わり以降に始まるほかのレイヤーも、取り除いた長さだけ左に詰めます。最後に再生ヘッドを詰めたレイヤーの始まりへ動かします。ショートカットは znd の設定で割り当てられます。

## 元との違い

- AviUtl2 では同じレイヤーの後ろのオブジェクトを詰めますが、znd では 1 レイヤーが 1 つのクリップなので、元の終わり以降に始まるレイヤーを詰めます。
- 再生ヘッドが選んだレイヤーの範囲の外にあるときは何もしません（元と同じ）。ロックしたレイヤーは動かしません。
