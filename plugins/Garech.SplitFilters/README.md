# フィルタ分離

オブジェクト上のフィルタ効果群を個別オブジェクト化するプラグイン

- 元のパッケージ: [フィルタ分離](https://github.com/Garech-mas/AviUtl2_SplitFilters)（作者: Garech、ライセンス: MIT）
- カタログ ID: `Garech.SplitFilters`

## znd での使い方

レイヤーを選んで、「プラグイン」メニューかレイヤーの右クリックから実行します。

- **フィルタ分離**: レイヤーのエフェクトを 1 つずつ、同じ長さ・位置の調整レイヤーに分けて上に置きます（掛かる順は元と同じ）
- **上のレイヤーへフィルタ結合**: エフェクトをすべて、すぐ上のレイヤーに移します
- **上のレイヤーへ先頭フィルタを結合**: 最初のエフェクトだけを、すぐ上のレイヤーに移します

## 元との違い

- AviUtl2 の「フィルタオブジェクト」は znd の調整レイヤーに当たります。
- 「フィルタ分離（グループ制御）」と「基本効果分離」はありません。znd にはグループ制御も、「基本効果」エフェクトもないためです（位置・回転などはレイヤーのトランスフォームと親子付けで扱います）。
