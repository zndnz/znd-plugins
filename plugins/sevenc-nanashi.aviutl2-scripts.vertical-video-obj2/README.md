# 縦動画ガイド.obj2

ニコニコショートのUIで隠れる部分を表示するためのスクリプト

- 元のパッケージ: [縦動画ガイド.obj2](https://github.com/sevenc-nanashi/aviutl2-scripts/blob/main/scripts/%E7%B8%A6%E5%8B%95%E7%94%BB%E3%82%AC%E3%82%A4%E3%83%89/README.md)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-scripts.vertical-video-obj2`

## znd での使い方

縦長のコンポの中央に置いた平面レイヤーにエフェクト「描画 › 縦動画ガイド」を掛けると、ニコニコショートの画面で UI（コメント欄・いいね・投稿者・ツールバーなど）に隠れる部分を色の付いた図形で示します。端末の画面の高さ（下の帯を除く）がコンポの高さに合います。書き出しに含めないよう、レイヤーをガイドレイヤーにしてください。

- デバイス: iPhone 16（iOS 26）/ iPad mini（iPadOS 26）
- 色・ピン留め動画・タグ・投稿者名の幅・左右線の幅

## 元との違い

- 元は書き出しのときに自動で消えますが、znd ではガイドレイヤーにすると書き出しに含まれません（「出力時にも表示」はガイドを外すのと同じです）。
- 元の PI（レイアウトの上書き）はありません。
