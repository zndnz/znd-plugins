# GParticle

全方向爆発・方向指定・コーン状・渦巻きのパーティクル。寿命の間に大きさ・色・不透明度が変わり、重力と空気抵抗が掛かる。

- 元のパッケージ: [GParticle](https://github.com/sagami121/GParticle)（作者: sagami121、ライセンス: MIT）
- カタログ ID: `sagami121.GParticle`

## znd での使い方

コンポの大きさの平面にエフェクト「シミュレーション › GParticle」を掛ける。発生源の位置はレイヤーの中心からの px。
加算などで重ねたいときは、レイヤーの描画モードを「加算」「スクリーン」にする。

## 元との違い

- 元は GPU のコンピュートシェーダーで計算する。ここでは同じ式（同じ乱数 PCG ハッシュ）を CPU で計算する。
- Z（奥行き）の位置・範囲・重力は無い（元も描画には Z を使っていない）。合成モードはレイヤーの描画モードで指定する。
