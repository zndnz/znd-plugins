# Palette History

色設定ウィンドウのパレットに使用した色の履歴を積み上げるプラグイン

- 元のパッケージ: [Palette History](https://github.com/teruyoshii/AviUtl2_Palette_History)（作者: てるよし、ライセンス: MIT）
- カタログ ID: `teruyoshii.Palette_History`

## znd での使い方

「プラグイン」メニューから「色の履歴」パネルを開くと、プロジェクトで使っている色（平面の色・テキストの塗り・シェイプの塗り・エフェクトの色）を、新しく使った順に最大 24 色並べます。色のボタンを押すと、選んだレイヤーの色をその色にします。「先頭の色をコピー」で #RRGGBB をクリップボードに入れます。

## 元との違い

- AviUtl2 では「色設定」ウィンドウのパレットに履歴を積みますが、znd の色の選び方にはパレットがないので、パネルに並べます。
- 履歴はパネルを開いているあいだ覚えています（パネルを開き直すと、プロジェクトにある色から作り直します）。
