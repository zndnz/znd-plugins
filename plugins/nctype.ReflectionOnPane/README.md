# ReflectionOnPane（ガラスへの映り込み）

窓ガラスに映り込んだような見た目にする。露光・色調・ぼかし・端のフェード・左右反転・二重像。

- 元のパッケージ: [aviutl2_script_ReflectionOnPane](https://github.com/nctype/aviutl2_script_ReflectionOnPane)（作者: nctype、ライセンス: MIT）
- カタログ ID: `nctype.ReflectionOnPane`

## znd での使い方

映り込ませるレイヤーにエフェクト「スタイライズ › ガラスへの映り込み（ReflectionOnPane）」を掛け、
**レイヤーの描画モードを「スクリーン」にする**（元のスクリプトはスクリーンで描く）。

## 元との違い

- 描画モード（スクリーン）はエフェクトからは変えられないので、レイヤー側で設定する。
- 「ミラー」は元では Y 軸回転 180°。znd では画像の左右反転として行う（3D レイヤーにしなくてよい）。
- AviUtl2 の「色調補正」はここでは同じ考え方の近似（コントラスト・彩度は %、ガンマ -100 で暗く、輝度 200 で 2 倍）で、数値の効き方は完全には一致しない。
- ぼかし・ずれの量はレイヤー座標の px（プレビュー解像度に合わせて縮む）。
