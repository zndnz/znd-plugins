# SceneChangeKit_S（自作シーンチェンジ）

シーンチェンジをタイムライン上で自作するための部品。前後のシーンの絵を取り出し、その上にフィルタ効果を重ねて演出を作る。

- 元のパッケージ: [aviutl2_script_SceneChangeKit_S](https://github.com/sigma-axis/aviutl2_script_SceneChangeKit_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.SceneChangeKit_S`

## znd での使い方

1. 前のシーン・次のシーンをそれぞれプリコンポ（またはレイヤー）にしておく。
2. コンポの大きさの平面を置き、エフェクト「トランジション › シーンの取り込み（SceneChangeKit_S）」を掛けて「シーン」に前（または次）のシーンのレイヤーを選ぶ。
   元のレイヤーは非表示にしてよい。
3. その後ろにブラー・マスク・不透明度のキーフレームなどを重ねて、だんだん隠れる（現れる）演出を作る。

「アルファチャンネルを維持」を外すと、透明な部分を黒で埋めて不透明にする（元の「前シーン」「次シーン」の同名の設定と同じ）。

## 元との違い

- AviUtl2 では「自作シーンチェンジ」オブジェクトがフレームバッファとオブジェクトを保存し、「前シーン」「次シーン」がそれを読み出す。
  znd には描画中のフレームバッファを保存する仕組みは無いので、他のレイヤーの絵を直接取り込む 1 つのエフェクトにまとめた。
  「フレームバッファをクリア」は、取り込み元のレイヤーを非表示にすることに当たる。
