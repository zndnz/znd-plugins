# 段階グラデーション

時間制御カーブで自由に調整できる段階グラデーション

- 元のパッケージ: [段階グラデーション](https://github.com/teruyoshii/Teruyoshi_AviUtl2_Scripts/blob/main/%E6%AE%B5%E9%9A%8E%E3%82%B0%E3%83%A9%E3%83%87%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3.anm2)（作者: てるよし、ライセンス: MIT）
- カタログ ID: `teruyoshii.stepGradation`

## znd での使い方

エフェクト「段階グラデーション」（カテゴリ「色調整」）を掛けると、開始色から終了色へのグラデーションを「段階数」の段に区切って（0 でなめらか）、合成モードと強さを選んで重ねます。

- 形状: 線形（「角度/内径」は角度）・円形（「角度/内径」は内径）
- 中心X・Y・幅、開始色・終了色とそれぞれの透明度
- 色空間: RGB / HSL短経路 / HSL長経路 / HSL右回り / HSL左回り
- グラデ曲線: 「グラデ曲線を使う」を入れると、「グラデ曲線0→100」に打ったキーフレームの変化（レイヤーの始まりから終わりまで）を、グラデーションの進み方の曲線として使います
- 元オブジェクトをクリア: 元の絵を消してグラデーションだけにします

## 元との違い

- 元の「時間制御」で描くグラデ曲線は、znd ではパラメータのキーフレームで描きます（イン点からアウト点までの値の変化を曲線として読みます）。
- 合成モードのアルファ加算・アルファ最大値・アルファ減算・アルファ加算2 はありません。
- 中心はプレビュー上のアンカーではなく数値で指定します。
