# グラデーション+

sRGB以外の色空間でグラデーション加工するスクリプト

- 元のパッケージ: [グラデーション+](https://github.com/azurite581/AviUtl2-GradientPlus)（作者: azurite、ライセンス: CC0-1.0）
- カタログ ID: `azurite.GradientPlus`

## znd での使い方

エフェクト「グラデーション+」（カテゴリ「色調整」）を掛けると、開始色から終了色へのグラデーションを、選んだ色空間で補間して重ねます（アルファは元のまま）。

- 色空間: sRGB / Linear sRGB / HSV / HSL / L*a*b / LCh / Oklab / Oklch。色相を持つ色空間では「補間経路」で色相環の短い側・長い側を選べます
- 形状: 線形・円形・矩形・凸形・角丸矩形と、それぞれのループ
- 中心X・Y・角度・幅、開始色・終了色とそれぞれの透明度
- 合成モード・強さ: 元の絵への重ね方

## 元との違い

- 中心はプレビュー上のアンカーではなく数値で指定します。
