# filter_effect_toggle.aux2

フィルタ効果とフィルタオブジェクトを切り替える機能を追加するプラグイン

- 元のパッケージ: [filter_effect_toggle.aux2](https://github.com/sevenc-nanashi/filter_effect_toggle.aux2)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.filter_effect_toggle-aux2`

## znd での使い方

レイヤーを選んでコマンド「エフェクトと調整レイヤーを切り替える」（「プラグイン」メニューとレイヤーの右クリック）を実行すると:

- 普通のレイヤーなら、そのエフェクトを同じ長さ・同じ位置の調整レイヤーに移して、すぐ上に置きます（下のレイヤー全部に掛かるようになります）
- 調整レイヤーなら、そのエフェクトをすぐ下のレイヤーに移し、調整レイヤーを消します

## 元との違い

- AviUtl2 の「フィルタ効果」と「フィルタオブジェクト」は、znd ではレイヤーのエフェクトと調整レイヤーに当たります。
