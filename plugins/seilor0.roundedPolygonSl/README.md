# 角丸正多角形_sl

角を丸めたり、星形にしたりできる正多角形。塗りと線（内側・中央・外側、角はマイター・ラウンド）。

- 元のパッケージ: [roundedPolygon_sl](https://github.com/seilor0/roundedPolygon_sl)（作者: seilor0、ライセンス: MIT）
- カタログ ID: `seilor0.roundedPolygonSl`

## znd での使い方

平面レイヤー（大きさは何でもよい）にエフェクト「描画 › 角丸正多角形_sl」を掛ける。平面の絵は図形に置き換わり、平面の中心に描かれる。

## 元との違い

- 「カスタムオブジェクト」の代わりに、平面に掛けるエフェクト（ABI 3 の出力の大きさの変更で図形の大きさになる）。
- 距離関数は元のシェーダーと同じ。色の合成はリニアライトで行う。
