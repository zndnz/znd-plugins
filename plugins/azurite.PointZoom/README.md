# ポイントズーム

指定した点を中心に、画像を拡大・縮小する（オブジェクトの大きさは変えない）。縮小したときの領域外は、指定色・引き伸ばし・ループ・ミラーから選ぶ。

- 元のパッケージ: [AviUtl2-PointZoom](https://github.com/azurite581/AviUtl2-PointZoom)（作者: azurite、ライセンス: MIT）
- カタログ ID: `azurite.PointZoom`

## znd での使い方

エフェクト「ディストーション › ポイントズーム」。目標座標はビューアでドラッグできる点（既定はレイヤーの中央）。
「補間なし」でドット絵のように拡大する。ループ・ミラーでは拡大率は 100% 以上になる。

## 元との違い

- 目標座標は中心からの相対値ではなく、レイヤー上の位置で指定する。
- 「指定色」は元と同じく、拡大後の絵の透明な部分（領域外を含む）をその色で埋める。透明度は領域外の部分にだけ掛かる。
- `PI`（パラメータ注入）は無い。
