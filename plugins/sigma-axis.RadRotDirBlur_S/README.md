# RadRotDirBlur_S（複合ブラー）

放射ブラー（拡大）・回転ブラー・方向ブラー（移動）を 1 つにした複合ブラー。色ごとにずらして色収差も付けられる。

- 元のパッケージ: [aviutl2_script_RadRotDirBlur_S](https://github.com/sigma-axis/aviutl2_script_RadRotDirBlur_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.RadRotDirBlur_S`

## znd での使い方

エフェクト「ブラー › 複合ブラー（RadRotDirBlur_S）」。中心はビューアでドラッグできる。相対位置 -100 で元の位置から先へ、100 で後ろへぼける。
ぼけた分だけ画像が広がる（「サイズ固定」で広げない）。精度は重ねる枚数（大きいほど滑らか・重い）。

## 元との違い

- ぼかしの計算は同じ（各段の拡大・回転・移動を直接求めて平均する。元は行列を順に掛ける）。
- 広げる大きさは、元の四隅と辺の中点の動きから求める（元は円弧の外接矩形を厳密に計算する）。
- 「回転中心を基準」「中心」（互換用）・`PI` は無い。
