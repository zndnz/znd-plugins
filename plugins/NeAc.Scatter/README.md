# Scatter

オブジェクトごとに、乱数で位置・回転・拡大をばらけさせる。progress を動かすと、ばらけた状態から元の位置へ集まる（または散る）。

- 元のパッケージ: [aviutl2_script_Scatter](https://github.com/nea-c/aviutl2_script_Scatter)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.Scatter`

## znd での使い方

1. ばらけさせたいレイヤーをタイムラインで選ぶ（複数可）。
2. 「プラグイン › Scatter」パネルで範囲（min/max）とシードを決め、「選択レイヤーに付ける」。
3. 各レイヤーに「Scatter」スライダー（%）が付くので、キーフレームで 100 → 0 などと動かす。

エクスプレッションから直接 `scatter(progress, seed, {x:[-160,160], y:[-90,90]}, index)` を呼ぶこともできる
（戻り値は `{x, y, z, rx, ry, rz, zoom}`）。

## 元との違い

- AviUtl2 の `obj.index`（個別オブジェクトの番号）の代わりに、パネルで選んだレイヤーの順番を使う。
  テキストを 1 文字ずつばらけさせるには、テキストを文字ごとのレイヤーに分けてから使う。
- znd のレイヤーは 2D の位置と z 回転が基本なので、パネルは x・y・回転・拡大を扱う（`scatter()` は z・rx・ry も返す）。
- 乱数の列は Lua の `math.random` と同じではない（同じシードでも同じ配置にはならない）。
