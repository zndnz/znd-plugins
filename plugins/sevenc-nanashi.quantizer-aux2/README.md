# quantizer.aux2

BPMグリッドから少しズレているオブジェクトを補正するプラグイン

- 元のパッケージ: [quantizer.aux2](https://github.com/sevenc-nanashi/quantizer.aux2)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.quantizer-aux2`

## znd での使い方

「プラグイン」メニューから「quantizer」パネルを開き、「探す」を押すと、コンポのビートグリッドから少し（「フレーム数」以内）ずれているレイヤーの開始・終了・キーフレームを一覧にします。一覧の「移動」でそのレイヤーを選んで再生ヘッドを動かし、「補正」でいちばん近いグリッドに合わせます。「すべて補正」で一度に合わせます。

- 対象: 開始位置・キーフレーム・終了位置（「コンポの終わり」を入れると、コンポの終わりちょうどで終わるものも対象）
- ソート: レイヤー順・フレーム順
- グリッドは コンポのビートグリッドの BPM と分割数で決まります

## 元との違い

- AviUtl2 の BPM グリッド（区間ごとに BPM を変えられる）ではなく、znd のコンポのビートグリッド（1 つの BPM）を使います。
- 開始を補正するときは、レイヤーの中身は動かさず開始位置だけを動かします。
- 元の「自動で次にジャンプ」はありません。
