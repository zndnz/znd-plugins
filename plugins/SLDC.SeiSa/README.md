# あとのせRTAタイマー（総タイム）SeiSa

録画に後から RTA のタイマーを載せる。区間ごとに「走行中」「中断中」が交互に切り替わり、走行中の区間だけ時間を数える（ロード時間の除外など）。

- 元のパッケージ: [aviutl2-script-seisa](https://github.com/samuelladoco/aviutl2-script-seisa)（作者: SLDC、ライセンス: MIT）
- カタログ ID: `SLDC.SeiSa`

## znd での使い方

1. テキストレイヤーを置き、フォント・大きさ・縁取りを決める。
2. 「プラグイン › あとのせRTAタイマー」パネルで設定し、テキストレイヤーを選んで「タイマーにする」。
3. そのテキストレイヤーに**レイヤーマーカー**を打つと、そこで区間が切り替わる（最初の区間は「奇数番目の区間でカウント」を外すと走行前）。

本文はエクスプレッション（`seisaText(thisLayer, time, …)`）で毎フレーム作られ、文字色は区間の状態ごとのアニメーターで変わる。

## 元との違い

- 区間は AviUtl2 の中間点ではなく、テキストレイヤーのマーカーで区切る。
- フォント・文字の装飾・文字揃えはテキストレイヤーの設定を使う。影・縁の色を状態ごとに変える機能は無い（文字色だけ）。
- 開始フレーム数が不正なときのエラー文は無い（0 未満は 0 にする）。
