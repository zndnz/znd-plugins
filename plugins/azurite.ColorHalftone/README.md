# ColorHalftone

カラーハーフトーン加工をするスクリプト

- 元のパッケージ: [AviUtl2-ColorHalftone](https://github.com/azurite581/AviUtl2-ColorHalftone)（作者: azurite、ライセンス: MIT）
- カタログ ID: `azurite.ColorHalftone`

## znd での使い方

エフェクト「カラーハーフトーン」（カテゴリ「加工」）をレイヤーに掛けると、絵を 3 色の網点に分解して描き直します。

- サイズ: 大きいほど網点が大きく（粗く）なります
- ドットサイズ: 網点 1 つの大きさの倍率（%）
- X・Y: 網の位置をずらします（px）
- 回転・ドット回転: 網全体の角度と、網点の形の角度
- 滑らかさ: 色を拾う前に掛けるぼかし
- 融合度: 隣り合う網点をなめらかにつなげます
- 形状: 円 / 四角形 / 三角形 / 五角形 / 六角形 / 星型 / ハート / 線
- 混色方法: 減法混色（色1～3 = シアン・マゼンタ・イエローを重ねて暗くする）/ 加法混色（色を重ねて明るくする。黒背景向け）
- 段違い: 1 行おきに網点を半分ずらします
- 背景色・背景色透明度・元のアルファを維持
- 色1～3・色1～3スクリーン角度・色1～3表示

## 元との違い

- 元の PI（色ごとにドットサイズや位置を変える指定）はありません。
- 「滑らかさ」のぼかしは znd のガウスぼかしで行うので、ぼけ方が少し違います。
- 透明な部分の色は、乗算済みアルファを戻してから背景色と混ぜます。
- 網点の形は Inigo Quilez の 2D SDF（MIT）を使っています（元と同じ）。
