# vintage.auf2

音声を昔のビデオっぽくするAviUtl2のフィルタプラグイン

- 元のパッケージ: [vintage.auf2](https://github.com/sevenc-nanashi/vintage.auf2)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.vintage-auf2`

## znd での使い方

音声のあるレイヤーにエフェクト「vintage」（カテゴリ「音声」）を掛けると、音を 1900 年ごろの録音のようにします（狭い帯域・回転むら・歪み・ランブル・ヒス・プチプチ音・粗い量子化）。Wet は加工した音を混ぜる割合（%）です。

## 元との違い

- 元は音声のかたまりごとにフィルタの状態や時刻を最初からやり直しますが、znd ではかたまりをまたいで続けるので、継ぎ目でノイズが出ません。
- 加工した音はモノラル（左右の平均）で、元の音と Wet の割合で混ぜます（元と同じ）。
