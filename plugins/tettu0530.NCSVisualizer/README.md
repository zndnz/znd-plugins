# NCSVisualizer

音に反応して膨らむ、点でできた球（NCS の動画のようなビジュアライザー）。格子の点をパーリンノイズで揺らし、半球に投影して遠近を付ける。

- 元のパッケージ: [NCSAudioVisualizer](https://github.com/Tettu0530/NCSAudioVisualizer)（作者: Tettu0530、ライセンス: MIT）
- カタログ ID: `tettu0530.NCSVisualizer`

## znd での使い方

コンポの大きさの平面にエフェクト「描画 › NCSVisualizer」を掛け、「音声レイヤー」に音楽のレイヤーを選ぶ（選ばなければ音に反応しない）。

## 元との違い

- 元は前のフレームの値に追従させて音の動きを滑らかにする（フレームを順に描かないと変わる）。znd では過去 0.5 秒の音を順にたどって同じ追従を計算するので、どのフレームから描いても同じ結果になる。
- 音の強さは FFT（2048 点、ハン窓）の振幅の平均を、AviUtl の `obj.getaudio` の「fourier」に近い目盛りにしたもの。感度の効き方は完全には一致しない。
- 「情報をログ出力」は無い。点は奥から順に描く。
