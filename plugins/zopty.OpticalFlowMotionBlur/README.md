# 光学モーションブラー

オプティカルフローを使った疑似モーションブラー

- 元のパッケージ: [光学モーションブラー](https://gist.github.com/zopty/51deda495876451c1dcfb09ceb05345d)（作者: zopty、ライセンス: BSD-3-Clause）
- カタログ ID: `zopty.OpticalFlowMotionBlur`

## znd での使い方

エフェクト「オプティカルフローモーションブラー」（カテゴリ「ぼかし」）を掛けると、前のフレームとの違いから絵の動きを求め、動いている向きにぼかします（動画の素材や、動きのあるレイヤーに）。

- 強度: ぼかす長さ、速度: 前のフレームで求めた動きを混ぜる割合（大きいほど動きがなめらかに続く）
- 高度な設定: フロー表示（求めた動きを色で見る）・最大フロー長・サンプル数・カーネル半径・しきい値・勾配スケール

## 元との違い

- 元は前のフレームの絵と動きを覚えて少しずつ混ぜていきますが、znd のエフェクトは状態を持たないので、毎回 1 つ前と 2 つ前のフレームから動きを求めて混ぜます。シークしても同じ結果になります。
- 計算（Lucas–Kanade 法・動きに沿ったぼかし）は元のシェーダーと同じです。
