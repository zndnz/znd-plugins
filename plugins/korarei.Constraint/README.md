# Constraint

テキストの横にアイコン画像を表示

- 元のパッケージ: [Constraint](https://gist.github.com/korarei/d5b089a69e0c8ba5903d641d677c89e8)（作者: Korarei、ライセンス: CC0-1.0）
- カタログ ID: `korarei.Constraint`

## znd での使い方

エフェクト「Constraint」（カテゴリ「配置」）をテキストなどのレイヤーに掛け、「Image Layer」でアイコンにするレイヤーを選ぶと、その絵を元の絵の上・右・下・左（Position）に並べます。元の絵の位置は動きません。

- Cross Offset: 並べる向きと直角の方向の揃え（-100 で左／上、100 で右／下）
- Padding: 元の絵とアイコンのすき間（px）
- Rotation・Scale: アイコンの回転と拡大率

## 元との違い

- アイコンは画像ファイルではなくレイヤーで選びます（元はファイルかレイヤー番号）。画像を使うときは、その画像のレイヤーを置いて非表示にしてください。
- 元はテキストを複数オブジェクトにしたときに組み直した大きさを使いますが、znd では掛けたレイヤーの絵の大きさをそのまま使います。
