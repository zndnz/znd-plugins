# 虹色グラデーションM

オブジェクトに虹色のグラデーションをかけます。

- 元のパッケージ: [虹色グラデーションM](https://x.com/momo_neeeko/status/2108488871327764937)（作者: もも猫、ライセンス: MIT）
- カタログ ID: `momo_neeeko.RainbowGradationM`

## znd での使い方

エフェクト「虹色グラデーションM」（カテゴリ「色調整」）を掛けると、色相が一巡するグラデーションを、合成モードと強さを選んで絵に重ねます（アルファは元のまま）。

- タイプ: 線形 / 円形 / 矩形 / 環状、中心X・Y・角度・幅（一巡する長さ。環状では角度）
- 繰り返す: 幅ごとにくり返すか、端で止めるか。反転: 向きを逆にする
- 色補間: HSV / HSV(補正)（黄や水色の幅を詰めて見た目の変化をそろえる）/ OKLAB（OKLCH の色相を回す）
- 基準色とシフト、または「数値で基準色を指定」で色相・彩度・明度を直接指定

## 元との違い

- 「数値で基準色を指定」の項目は、元のように色補間で出し分けず、HSV 用と OKLAB 用を両方並べています（使うのは色補間に合うほう）。
- 中心はプレビュー上のアンカーではなく数値で指定します。
