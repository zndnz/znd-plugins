# 連結ライン

2 つのオブジェクトを線でつなぐ。実線・点線（流れる点線）、平らな端・丸い端、始点・終点の空き、表示割合（線が伸びる演出）。

- 元のパッケージ: [connection_line](https://github.com/ar-ca-na/connection_line)（作者: arcana、ライセンス: MIT）
- カタログ ID: `arcana.connection_line`

## znd での使い方

タイムラインでつなぎたい 2 つのレイヤーを選び、「プラグイン › 選んだ 2 つのレイヤーを線でつなぐ」。
コンポの大きさの平面「連結ライン（A — B）」が一番上に足され、そのエフェクトの始点・終点が 2 つのレイヤーの位置に追従する
（エクスプレッション `thisComp.layer("A").toComp(…)`）。始点・終点のオフセットは、エクスプレッションの数値を書き換える。

エフェクト「描画 › 連結ライン」を直接使い、始点・終点を手で動かしてもよい。

## 元との違い

- 対象はレイヤー番号ではなく、コマンドで選んだレイヤー（名前で参照する）。
- 奥行き（3D のカメラ）の扱い（「奥行き」）は無い。znd のこのエフェクトは 2D の画面上で線を引く。
