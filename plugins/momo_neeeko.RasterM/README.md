# ラスターM

様々な波形で向きが指定できるラスター

- 元のパッケージ: [ラスターM](https://x.com/momo_neeeko/status/2041081558011093323)（作者: もも猫、ライセンス: MIT）
- カタログ ID: `momo_neeeko.RasterM`

## znd での使い方

エフェクト「ラスターM」（カテゴリ「変形」）を掛けると、角度の向きに並んだ波で絵をずらします。波長（0 なら振幅×4）・振幅・位相（度）・波形（正弦波 / 三角波 / 矩形波 / ノコギリ波 / 正弦波の絶対値 / ランダム）を選べます。ずれる分だけ周りを広げます。

## 元との違い

- 計算は元のシェーダーと同じです（ランダムの乱数は GPU と CPU の sin の精度差で並びが変わることがあります）。
