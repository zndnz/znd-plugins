## znd での使い方

エフェクト「CRTディスプレイ風」（カテゴリ「加工」）を掛けると、ブラウン管の画面のようにします（走査線が上から順に光って減衰する・RGB の縦縞・横のにじみ・画素の格子）。画面全体に掛けるときは調整レイヤーに掛けてください。

- 水平ブラー: 横のにじみ
- RGB%: RGB の縦縞の強さ
- ピクセルサイズ: 1 画素（RGB 3 本の縞）の大きさ
- 減衰: 走査線が光ってから暗くなるまでの長さ
- スローモーション: 走査の速さを遅くする倍率（1 で 60Hz）
- プログレッシブ: 入れると 1 行ずつ、入れないと 1 行おき（インターレース）に走査します

## 元との違い

- 計算は元のシェーダーと同じです。元の PI はありません。
