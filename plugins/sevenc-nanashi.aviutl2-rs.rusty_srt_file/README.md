# Rusty SRT File Plugin

SRTファイル(字幕)のインポート/エクスポートを行うプラグイン

- 元のパッケージ: [Rusty SRT File Plugin](https://github.com/sevenc-nanashi/aviutl2-rs)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-rs.rusty_srt_file`

## znd での使い方

コマンドが 2 つ入っています（「プラグイン」メニューとレイヤーの右クリック）。

- **SRT ファイルを読み込む**: ひな形にするテキストレイヤーを 1 つ選んで実行し、SRT ファイルを選ぶと、字幕 1 つにつき 1 つのテキストレイヤーを作ります（フォントや位置などはひな形と同じ）。時刻はひな形の開始位置を 0 秒として並べ、フレームに丸めます。ひな形のレイヤーは消えます。
- **SRT ファイルに書き出す**: 選んだテキストレイヤー（選んでいなければコンポのすべてのテキストレイヤー）の開始・終了時刻と文字を、時刻順に SRT ファイルに書き出します。

## 元との違い

- 元はタイムラインのオブジェクトを並べ直しますが、znd ではテキストレイヤーを 1 字幕 1 レイヤーで作ります。
- 書き出しは、選んだテキストレイヤーか、コンポのすべてのテキストレイヤーが対象です。
- 重なった字幕は、前の字幕の終わりまで開始を遅らせます（元と同じ）。
