# スピード線

画面の上下（「縦方向」で左右）に、流れる線を描く（漫画の効果線のような演出）。

- 元のパッケージ: [aviutl2_script_SpeedLine](https://github.com/nea-c/aviutl2_script_SpeedLine)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.SpeedLine`

## znd での使い方

コンポの大きさの平面にエフェクト「描画 › スピード線」を掛ける。幅は線が出る帯の幅（上下の合計、px または「幅を割合に」で 0〜4000 を画面に対する割合）、
ぼかしは帯の内側の境目の柔らかさ、速度は線の流れる速さ（px/秒）、周期 X・Y は線の長さと間隔（大きいほど短く・細かく）。

## 元との違い

- 元は AviUtl2 の組み込みフィルタ（背景・斜めクリッピング・ノイズ・単色化）を組み合わせて作る。znd にはそれらと同じフィルタが無いので、
  同じ手順（中央の帯を抜く → 筋状のノイズをアルファに掛ける → 濃さ・薄さでしきい値 → 単色）を 1 つのエフェクトの中で行う。
  ノイズの模様は AviUtl2 の「ノイズ」と同じではない（周期の数値の効き方も近いが同じではない）。
- 「無印ノイズを使用」「前にエフェクトを適応」は無い。
