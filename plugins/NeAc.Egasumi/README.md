# エ霞

日本画の「エ霞（すやり霞）」の形の雲を描く。横長の雲を最大 5 つ、つなぎでつないだ形。

- 元のパッケージ: [aviutl2_script_Egasumi](https://github.com/nea-c/aviutl2_script_Egasumi)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.Egasumi`

## znd での使い方

平面レイヤー（コンポの大きさがよい）にエフェクト「描画 › エ霞」を掛ける。雲 1 つにつき 2 点（左端・右端）、つなぎに 1 点があり、ビューアでドラッグできる。
「高さ統一」（既定）では縦の位置は雲高さ・繋ぎ高さから自動で決まり、横の位置だけを点で決める。

## 元との違い

- 元の「アンカー」（点の列）は、14 個の点のパラメータ（点 1〜14）になった。使うのは雲個数に応じた最初の 2 + 3×(個数−1) 個。
- 元は描いた後に「境界ぼかし」（2px）を掛ける。znd では最初からアンチエイリアス付きで描くので掛けていない。
