# Canny

ノイズを抑えて輪郭を細くきれいに出すCanny風エッジ抽出スクリプト

- 元のパッケージ: [Canny](https://github.com/CatWithNeko/aviutl2-scripts)（作者: こんにゃくねこ、ライセンス: CC0-1.0）
- カタログ ID: `CatWithNeko.Canny`

## znd での使い方

エフェクト「Canny」（カテゴリ「抽出」）を掛けると、輪郭を細い白い線として取り出し、ほかを透明にします。

- Blur: 先に掛けるぼかし（ノイズを抑える）
- High・Low: 強いエッジ・弱いエッジの閾値
- Connect: 強いエッジにつながる弱いエッジを強いエッジにする回数

## 元との違い

- 勾配の大きさは元の「エッジ抽出」の代わりに Sobel で計算します。
- 最後の透過は元の「ルミナンスキー」の代わりに、強いエッジ以外を透明にします。
