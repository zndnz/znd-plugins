# ColoredCollar_S（色付き縁取り）

オブジェクトの境界の色を外へ引き延ばしたり、距離に応じた色のグラデーションで縁取る。色の濃さ 0 で境界の色をそのまま延ばし、100 で縁色の単色。

- 元のパッケージ: [aviutl2_script_ColoredCollar_S](https://github.com/sigma-axis/aviutl2_script_ColoredCollar_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.ColoredCollar_S`

## znd での使い方

エフェクト「スタイライズ › 色付き縁取り（ColoredCollar_S）」。縁の分だけ画像が広がる（「サイズ固定」で広げない）。外側の色を別にすると、内側の縁色から外側の縁色へのグラデーションになる。

## 元との違い

- 計算は元と同じ（ジャンプフラッド法で最寄りの不透明画素を求め、その周りの色と距離から縁を作る）。「錯視軽減」は距離と色を箱型にならす近似（元は 4 回の畳み込み）。
- 「縁色外側」を使うかどうかは「外側の色を別にする」で切り替える（元は色を空にするかどうか）。`PI` は無い。
