# object_as_frame_selection.aux2

選択したオブジェクトの範囲をフレーム選択範囲にするプラグイン

- 元のパッケージ: [object_as_frame_selection.aux2](https://github.com/sevenc-nanashi/object_as_frame_selection.aux2)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.object_as_frame_selection-aux2`

## znd での使い方

レイヤーを選んでコマンド「レイヤーの範囲をワークエリアにする」（「プラグイン」メニューとレイヤーの右クリック）を実行すると、そのレイヤーの始まりから終わりまでがワークエリアになります。複数選ぶと、全体を囲む範囲になります。

## 元との違い

- AviUtl2 の「フレーム選択範囲」は znd のワークエリアに当たります。
