# BlockNoise

一定時間ごとに、画像の一部を長方形のブロックとして切り出し、ずらして重ねるグリッチ。

- 元のパッケージ: [Aviutl2-BlockNoise](https://github.com/sagami121/Aviutl2-BlockNoise)（作者: sagami121、ライセンス: MIT）
- カタログ ID: `sagami121.BlockNoise`

## znd での使い方

エフェクト「スタイライズ › ブロックノイズ」。しきい値より大きい乱数が出た区間だけブロックが出る（しきい値 80 で約 2 割の区間）。
変化（ms）ごとに配置が変わる。サイズ・ずれはレイヤー座標の px（「ずれ%指定」でブロックの大きさに対する %）。

## 元との違い

- 元の「範囲（W/H）」（ブロックを置く範囲）は、エフェクトを掛けたレイヤーの大きさになる。調整レイヤーに掛ければ画面全体。
- 元の「個別」（ブロックごとに後続のフィルタを掛ける）は無い。
- 乱数の列は AviUtl の `obj.rand` と同じではない（配置は違うが、性質は同じ）。
