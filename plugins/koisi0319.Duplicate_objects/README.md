# オブジェクト行複製

選択したオブジェクトをそのレイヤーに複製するスクリプト

- 元のパッケージ: [オブジェクト行複製](https://github.com/koisi0319/Aviutl2-Duplicate-objects-at-equal-intervals)（作者: koisi0319、ライセンス: MIT）
- カタログ ID: `koisi0319.Duplicate_objects`

## znd での使い方

「プラグイン」メニューから「オブジェクト行複製」パネルを開き、レイヤーを選んで「複製する」を押すと、そのレイヤーを後ろへ続けて複製します。前の複製の終わりから次の始まりまで「すき間（フレーム）」を空けます。数は「回数」か、「開始がこのフレームまで」で決めます（コンポの終わりを越えては作りません）。

## 元との違い

- AviUtl2 では同じレイヤーの上に並べますが、znd では 1 レイヤーが 1 つのクリップなので、複製は元のレイヤーの上に別のレイヤーとして作ります。
- 元の「重なったら止める」はありません（別のレイヤーになるので重なりません）。
