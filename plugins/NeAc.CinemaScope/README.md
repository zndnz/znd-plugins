# シネマスコープ

画面の上下（任意の角度）に帯を描き、シネマスコープ風の画面にする。

- 元のパッケージ: [aviutl2_script_CinemaScope](https://github.com/nea-c/aviutl2_script_CinemaScope)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.CinemaScope`

## znd での使い方

コンポと同じ大きさの平面を一番上に置き、エフェクト「描画 › シネマスコープ」を掛ける。平面の色は無視され、帯の色で塗られる。
幅は残す部分の半分の高さ（px、またはスクリーンの幅・高さの半分に対する %）。幅 0 で全面を塗る（幅をキーフレームで広げると帯が開く）。

## 元との違い

- 元の「追加オプション 1・2」（同じ値を足し合わせるための予備のトラック）は無い。znd ではキーフレームとエクスプレッションで同じことができる。
- 中心はレイヤー上の位置（既定は中央）。
