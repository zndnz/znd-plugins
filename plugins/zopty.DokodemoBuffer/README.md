# どこでもバッファ

他のオブジェクトの絵や、自分の過去の絵を取り込んで重ねる。入出力・遅延・残像・ディスプレイスメントの 4 つのエフェクト。

- 元のパッケージ: [DokodemoBuffer](https://github.com/zopty/DokodemoBuffer)（作者: zopty、ライセンス: MIT）
- カタログ ID: `zopty.DokodemoBuffer`

## znd での使い方

| エフェクト（「どこでもバッファ」） | 内容 |
|---|---|
| 入出力 | 「取り込むレイヤー」の絵を、このレイヤーに合成モード（通常・置換・加算・マスク・型抜き）で重ねる |
| 遅延 | このレイヤーの N フレーム前の絵を下に重ねる |
| 残像 | N フレームおきの過去の絵を、残像数だけ重ねる |
| ディスプレイスメント | 「マップのレイヤー」の RGB の値に比例して、絵を移動・拡大・回転する（色収差付き） |

## 元との違い

- 元は「ID」で名前を付けたバッファに絵を保存し、別のオブジェクトで取り出す。znd では取り出す側が LAYER パラメータで取り込み元のレイヤーを直接選ぶ。
  過去の絵は保存せず、そのときの時刻の絵を描き直して取得する（フレームを順に描かなくても同じ結果になる）。
- 遅延・残像の過去の絵は、このレイヤーのエフェクトを掛ける前の絵。
