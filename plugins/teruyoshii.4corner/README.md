# 四隅に配置

対象を画面の四隅に複製配置。余白調整,個別回転,反転,拡縮,透明化可能

- 元のパッケージ: [四隅に配置](https://github.com/teruyoshii/Teruyoshi_AviUtl2_Scripts/blob/main/%E5%9B%9B%E9%9A%85%E3%81%AB%E9%85%8D%E7%BD%AE.anm2)（作者: てるよし、ライセンス: MIT）
- カタログ ID: `teruyoshii.4corner`

## znd での使い方

エフェクト「四隅に配置」（カテゴリ「配置」）を掛けると、レイヤーの絵を画面（コンポ）の四隅に 4 つ並べます。レイヤーはコンポの中心に置いてください（並べた絵はレイヤーの中心が画面の中心にあるものとして置きます）。

- 余白X・Y と配置方法: 画面の端から（または中心から）の距離。パーセントでも指定できます
- 全体サイズと隅ごとのサイズ、全体回転と隅ごとの回転、隅ごとの透明度
- 左右反転・上下反転: 右側・下側の絵を鏡写しにします（回転の向きも鏡写しになります）

## 元との違い

- 「個別オブジェクトとして描画する」はありません。znd ではエフェクトの結果は 1 枚の絵です。
