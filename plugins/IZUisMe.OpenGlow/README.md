# Open Glow

光学に基づいて自然に減衰する美しいグロー

- 元のパッケージ: [Open Glow](https://github.com/IZUisMe/aviutl2-open-glow)（作者: 絵に描いた虹、ライセンス: MIT）
- カタログ ID: `IZUisMe.OpenGlow`

## znd での使い方

エフェクト「Open Glow」（カテゴリ「光効果」）を掛けると、明るい部分から、距離のべき乗で自然に減衰する光を広げます。

- 強さ・拡散（光の届く半径の目安 px）・減衰（大きいほど光が中心に集まる）
- しきい値（%）: これより暗い部分は光らない（境目はなめらか）
- ガンマ: 光を足す計算の前後に使うガンマ
- 合成モード: リニア加算 / スクリーン / グローのみ
- 光色を使う・光色: 光に色を付ける
- 縦横比・角度: 光を一方向に伸ばす（正で横、負で縦に伸ばしてから角度だけ回す）
- サイズ固定: 光の広がる分だけ周りを広げない

## 元との違い

- 元のディザ（8bit で起こる縞を防ぐ）はありません。znd は浮動小数で計算するので不要です。
- 元は前処理で縮小する向きにテントフィルタで読み、仕上げは Catmull-Rom で読みますが、znd ではどちらもバイリニアで読みます。
- 元は処理量に上限を設けて大きな絵を縮めて計算しますが、znd では縮めません。
- 光色の有無は「光色を使う」で切り替えます（元は色を未設定にすると無効）。
