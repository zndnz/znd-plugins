# 目標指定拡大縮小.anm2

目標のピクセル数を指定し拡大縮小を行うスクリプト

- 元のパッケージ: [目標指定拡大縮小.anm2](https://github.com/sevenc-nanashi/aviutl2-scripts/blob/main/scripts/%E7%9B%AE%E6%A8%99%E6%8C%87%E5%AE%9A%E6%8B%A1%E5%A4%A7%E7%B8%AE%E5%B0%8F/README.md)（作者: Nanashi.、ライセンス: MIT）
- カタログ ID: `sevenc-nanashi.aviutl2-scripts.targeted-scale-anm2`

## znd での使い方

「プラグイン」メニューから「目標指定拡大縮小」パネルを開き、目標幅・目標高さとモードを決めてレイヤーを選び「付ける」を押すと、縦横比を保ったまま絵がその大きさになるよう、拡大率にエクスプレッションを付けます。絵の大きさが変わっても毎フレーム付いていきます。

- 下限指定: 範囲を埋める大きさ（CSS の cover）
- 上限指定: 範囲に収まる大きさ（CSS の contain）
- 幅指定・高さ指定: 幅（高さ）が目標になる大きさ

エクスプレッション関数 `targetedScale(value, 幅, 高さ, モード)` は手で書いても使えます。

## 元との違い

- 元はエフェクトとして拡大率を書き換えますが、znd では拡大率のエクスプレッションで同じことをします。
- 元の PI とデバッグモードはありません。
