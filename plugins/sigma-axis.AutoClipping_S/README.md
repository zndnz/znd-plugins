# AutoClipping_S（余白除去）

オブジェクトの不透明ピクセルを探し、それを含む最小の大きさになるよう上下左右端をクリッピングする。

- 元のパッケージ: [aviutl2_script_AutoClipping_S](https://github.com/sigma-axis/aviutl2_script_AutoClipping_S)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.AutoClipping_S`

## znd での使い方

エフェクト「クリッピング › 余白除去（AutoClipping_S）」をレイヤーに掛ける。

| パラメータ | 内容 |
|---|---|
| αしきい値（%） | これより不透明な画素を「中身」とみなす |
| 上下左右余白 | 切り詰めた後に足す余白（px）。負の値でさらに削る |
| 上下左右除去 | その辺の透明部分を切り詰めるか |

## 元との違い

- 「中心の位置を変更」は無い。znd ではエフェクトが画像の大きさを変えても絵の位置は保たれ、
  回転・拡大の中心はレイヤーのアンカーポイント（トランスフォーム）で決まるため。
- `PI`（パラメータ注入）は無い。値はエクスプレッションで動かせる。
- テキスト・シェイプレイヤーはコンポ全体の大きさのバッファに描かれるため、余白を足しても画面の外には広がらない。
