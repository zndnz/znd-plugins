# Leave Color

色抜き

- 元のパッケージ: [Leave Color](https://github.com/CatWithNeko/aviutl2-scripts#leave-color)（作者: こんにゃくねこ、ライセンス: CC0-1.0）
- カタログ ID: `CatWithNeko.LeaveColor`

## znd での使い方

エフェクト「Leave Color」（カテゴリ「色調整」）を掛けると、Color と色の向き（RGB の比率）の近さが Threshold（%）未満の画素を灰色にします。Invert を入れると逆に、近い色を灰色にします。Lum Mode は灰色にするときの輝度の式です。

## 元との違い

- 元と同じく表示値（sRGB）で計算します。
