# 多角形モーフ_F

頂点数の違う正多角形（星形・角丸・線）の間を、頂点が回り込むように（または直線的に）滑らかにモーフィングする。

- 元のパッケージ: [AviUtl2_PolygonMorph_F](https://github.com/fu-majime/AviUtl2_PolygonMorph_F)（作者: Fu-Majime、ライセンス: MIT）
- カタログ ID: `Fu-Majime.AviUtl2_PolygonMorph_F`

## znd での使い方

平面レイヤーにエフェクト「描画 › 多角形モーフ_F」を掛け、開始・終了の頂点数を決めて「モーフ（%）」を 0 → 100 とキーフレームで動かす。
ライン幅がサイズ以上なら塗りつぶし、それより小さいと線（内側は背景色）。

## 元との違い

- 元は「頂点数」トラックの区間の両端の値からモーフ元・先を決める。znd ではエフェクトに区間の情報が渡らないので、開始・終了の頂点数とモーフの進行度を別のパラメータにした。
  回転補正も開始・終了で別に指定する。
- 距離関数は元のシェーダーと同じ（モーフ中の多角形の頂点は 1 回だけ計算する）。`PI` は無い。
