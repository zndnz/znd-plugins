# SliceGlitch

簡単な操作でスライスグリッチを作成できるエフェクトです。

- 元のパッケージ: [SliceGlitch](https://note.com/isuzu_hinode/n/n3a7d7b761b98)（作者: 暘 弥涼、ライセンス: MIT）
- カタログ ID: `hinodeisuzu.sliceglitch`

## znd での使い方

エフェクト「SliceGlitch」（カテゴリ「加工」）を掛けると、毎フレームいくつかの横の帯を左右にずらし（スライス）、赤と青を逆向きにずらし（色収差）、絵全体を揺らします（振動）。

「低音に連動(音声)する」を入れると、「音声レイヤー」で選んだレイヤーの低音の強さに合わせて振動が大きくなります（「色収差も低音で増幅」で色収差も）。入れないときは常に最大の強さで揺れます。

## 元との違い

- 元はシーン全体の音を使いますが、znd では音声レイヤーを選びます（選ばないと低音は 0）。
- 低音の強さは 40～400Hz の振幅から作るので、元とは目盛りが少し違います。
- 色ずれは元の「色ずれ」フィルタの代わりに、赤と青を左右に同じ幅だけずらします。
