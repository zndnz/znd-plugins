# ブラインドループ

斜めクリッピングを連続して並べたような効果を追加します。

- 元のパッケージ: [ブラインドループ](https://gist.github.com/zopty/ff3439d79fe609c7714d6db4ef1a39a6)（作者: zopty、ライセンス: BSD-3-Clause）
- カタログ ID: `zopty.BlindLoop`

## znd での使い方

エフェクト「ブラインドループ」（カテゴリ「クリッピング」）を掛けると、角度の向きの縞（1 周期が 幅×2 px）で絵を切り抜きます。割合（%）は消える部分の割合、位相（度）で縞を動かします。

## 元との違い

- 計算は元のシェーダーと同じです。
