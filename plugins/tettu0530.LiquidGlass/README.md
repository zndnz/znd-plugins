# Liquid Glass

オブジェクトの形のガラス越しに、背景が屈折して見える（Apple の Liquid Glass 風）。縁の丸みで背景がずれ、色収差・ハイライト・すりガラス・ガラスの色が付く。

- 元のパッケージ: [Liquid-Glass](https://github.com/Tettu0530/Liquid-Glass)（作者: Tettu0530、ライセンス: MIT）
- カタログ ID: `tettu0530.LiquidGlass`

## znd での使い方

1. 背景（ガラスの後ろに見せたいもの）を 1 つのプリコンポにして置く。
2. ガラスの形（シェイプレイヤーや、コンポの大きさの平面にマスクを切ったものなど）にエフェクト「スタイライズ › Liquid Glass」を掛け、「背景レイヤー」に 1 のプリコンポを選ぶ。

## 元との違い

- 元はそれまでに描いたフレームバッファを背景にする。znd では背景のレイヤーを選ぶ。背景の絵は、エフェクトを掛けたレイヤーの画像の大きさに合わせて取り込まれるので、
  ガラスはコンポ全体の大きさのレイヤー（シェイプ・テキスト、またはコンポの大きさの平面）に掛ける。
- 「計算解像度」（AviUtl2 のバッファの容量対策）と「距離場を確認」は無い。計算は元のシェーダーと同じ。
