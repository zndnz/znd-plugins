# 放射クリッピング

オブジェクトの中心から放射状に、扇形の領域を交互に透明にする。

- 元のパッケージ: [Radial-Clipping](https://github.com/supernyan74/Radial-Clipping)（作者: supernyan74、ライセンス: MIT）
- カタログ ID: `supernyan74.RadialClipping`

## znd での使い方

エフェクト「クリッピング › 放射クリッピング」。数（扇形の個数）・基準角（0° で右方向が透明な扇形の中心、時計回り）・割合（透明にする扇形の幅の割合）。

## 元との違い

同じ計算（境界線からの距離で 1px のアンチエイリアス）。中心はレイヤー画像の中心。
