# 最背面に配置（Layback）

オブジェクトを、それまでに描かれたすべてのものの後ろに置く。

- 元のパッケージ: [aviutl2_script_Layback](https://github.com/sigma-axis/aviutl2_script_Layback)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.Layback`

## znd での使い方

レイヤーを選び、「プラグイン › 最背面に配置」（またはタイムラインのレイヤーの右クリック › プラグイン）。
逆向きの「最前面に配置」も付けた。

## 元との違い

AviUtl2 ではフィルタとしてフレームバッファの後ろに描くが、znd ではレイヤーの重なり順が明示的なので、
レイヤーの順番そのものを動かすコマンドにした（描画結果は同じ）。取り消しできる。
