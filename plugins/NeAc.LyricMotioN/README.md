# LyricMotioN

歌詞（テキスト）の文字を、順番に少しずつずらしながら上下左右のどれかの方向から入れる（出す）モーション。

- 元のパッケージ: [aviutl2_script_LyricMotioN](https://github.com/nea-c/aviutl2_script_LyricMotioN)（作者: 猫愛、ライセンス: MIT）
- カタログ ID: `NeAc.LyricMotioN`

## znd での使い方

テキストレイヤーを選び、「プラグイン › LyricMotioN」パネルで設定して「付ける」。
「LyricMotioN: …」という名前のアニメーター（位置 ±X/±Y・拡大・不透明度）が付き、文字ごとの量はエクスプレッションセレクターの
`lyricMotionAmount()` が計算する。順序（先頭・末尾・中央・外側・ランダム）・ズレ・向き（連続して同じ向きにしない「被りあり」）も元と同じ。

## 元との違い

- 元は「動き」トラックに打ったキーフレームの動きをなぞる。znd ではパネルの「動き」でイージングを選ぶ。
- Z 方向の動き（±Z）は無い（znd のテキストのアニメーターは 2D）。
- 付けたときのイン点・アウト点を使うので、レイヤーの長さを変えたら付け直す。乱数の列は Lua の `math.random` と同じではない。
