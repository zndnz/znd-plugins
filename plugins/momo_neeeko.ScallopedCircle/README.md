# スカラップ円

スカラップ円のカスタムオブジェクト

- 元のパッケージ: [スカラップ円](https://x.com/momo_neeeko/status/2040680596410941589)（作者: もも猫、ライセンス: MIT）
- カタログ ID: `momo_neeeko.ScallopedCircle`

## znd での使い方

平面レイヤーにエフェクト「描画 › スカラップ円」を掛けると、平面の中心に、円周を波形で波打たせた図形を描きます（元の絵は置き換わります）。

- 波形: 正弦波 / 三角波 / 矩形波 / ノコギリ波 / 正弦波の絶対値
- 振幅%: サイズに対する波の高さ、山の数: 一周の山の数
- 歪み補正: 山の形を角度ではなく直線の上で作り、山がゆがまないようにします

## 元との違い

- 縁は超標本化でなめらかにします（元はアンチエイリアスなし）。
