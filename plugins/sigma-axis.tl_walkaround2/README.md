# TLショトカ移動2

タイムライン操作のコマンドを追加するプラグイン

- 元のパッケージ: [TLショトカ移動2](https://github.com/sigma-axis/aviutl2_tl_walkaround2)（作者: σ軸、ライセンス: MIT）
- カタログ ID: `sigma-axis.tl_walkaround2`

## znd での使い方

「プラグイン」メニューに「TLショトカ移動2: 〜」のコマンドが入ります。znd の設定でショートカットキーを割り当てて使ってください。

- 左/右の中間点・境界（レイヤー / コンポ）: 選んだレイヤー（またはコンポ全体）の始点・終点（とキーフレーム）へ再生ヘッドを動かす
- 左/右のマーカー、マーカーへ移動 1〜10: コンポのマーカーへ
- 選択レイヤーへ移動: 選んだレイヤーが見えるいちばん近い位置へ
- 小節線・拍・1/N 拍へ移動（BPM）: コンポのビートグリッドに沿って動く（1/N は分割数）
- グリッド基準線を左/右へ・現在フレームに、最寄りの小節線を現在フレームに
- 上/下のレイヤーを選択、選択レイヤーの始点/終点を現在フレームに、表示/非表示、マーカーを追加/削除

## 元との違い

- タイムラインのスクロールのコマンドはありません（znd のスクリプトからタイムラインの表示位置は動かせません）。
- 「左/右に選択オブジェクトを詰める」「オブジェクトを右へ複製」などは、znd では 1 レイヤーが 1 つのクリップなので入れていません（複製は znd の組み込み、詰めるのはリップル削除の移植が使えます）。
- 「カーソル位置を元に戻す」と、設定ウィンドウ（移動量・BPM 移動分母など）はありません。1/N 拍の N はビートグリッドの分割数です。
