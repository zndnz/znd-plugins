# カラーリンク

「カラーマスター」に 3 色を持たせ、下にあるレイヤーの「カラーリンク」がその色で単色化する。マスターの色を変えるだけで、つないだレイヤーの色がまとめて変わる。

- 元のパッケージ: [aviutl2-colorlink](https://github.com/InuyoshiAtom/aviutl2-colorlink)（作者: InuyoshiAtom、ライセンス: MIT）
- カタログ ID: `InuyoshiAtom.ColorLink`

## znd での使い方

1. 色を管理するレイヤー（何でもよい。ヌルや非表示の平面など）を選び、「プラグイン › カラーマスターを付ける」。色 A〜C を決める。
2. 色を揃えたいレイヤー（マスターより下）を選び、「カラーリンク: 色A につなぐ」など。
   「カラーリンク」エフェクトが付き、その色がマスターの色にエクスプレッションでつながる。

## 元との違い

- 元のカラーリンクは描画のたびに上のレイヤーを探す。znd ではコマンドを実行したときに最も近いマスターを探し、
  エクスプレッション（`thisComp.layer("…").effect("カラーマスター")("color_a")`）でつなぐ。後からレイヤー名を変えたときは、つなぎ直す。
- 単色化は表示値（sRGB）で行う。「強さ」「輝度を保持する」を付けた（元は強さ 100・輝度を保持しない固定）。
